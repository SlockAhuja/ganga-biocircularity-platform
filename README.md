## 📌 1. Project Overview & Institutional Purpose

This repository houses the unified **Academic Research, Collaboration & Interdisciplinary Innovation Platform**. The platform serves as a modern, research-grade showcase and interactive analytical portal designed for presentation to universities, funding agencies (DST, CSIR, ISRO, NRF, CEFIPRA), national laboratories, and academic collaborators.

### Key Objectives
1. **Academic & Research Dissemination**: Present foundational and applied research thrusts in **Metamaterials, Metasurfaces, Flexible/Wearable Antennas, Millimeter-Wave 5G/6G, AI/ML Computational Electromagnetics, and Semiconductor Devices**.
2. **Institutional Collaboration Hub**: Provide transparent, structured engagement modalities for **Faculty Sabbaticals, Student Research Internships, Joint Grant Proposals, FDPs/Workshops, and Capstone Mentorship**.
3. **Institutional Synergies**: Articulate partnerships with premier institutes (**BITS Pilani, CSIR-CEERI, SeoulTech, IIT Bombay, IUT Angoulême / Université de Poitiers, MIT-ADT University**) with strict academic integrity (distinguishing existing associations, proposed linkages, and potential collaborations).
4. **Flagship Live GIS Platform — Ganga Biocircularity**: Embed a multi-spectral Earth Observation (Sentinel-2) and bioeconomic intelligence suite modeling invasive water hyacinth extraction, CSTR anaerobic digestion kinetics, Bio-CNG vehicular fuel recovery, and organic fertilizer production.

## 🌿 6. Flagship: Ganga Biocircularity Intelligence Platform

Embedded directly in this repository is the complete interactive **Ganga Biocircularity Intelligence Platform**:
* **Ganga River Monitoring Map**: High-resolution hydrographic vector GIS canvas across the Prayagraj confluence ($18.5\text{ km}$ stretch) with Sentinel-2 L2A optical indices (`NDVI`, `NDWI`, `FAI`).
* **Interactive Zone Inspection**: Clickable hotspots (Zone 01 to Zone 09) detailing macrophyte density, total biomass tonnage, and confidence score.
* **Diurnal Water Quality Sensor Matrix**: Real-time telemetric logging for sensor buoys measuring $\text{pH}$, $\text{DO}$ ($3.9\text{ mg/L}$), $\text{BOD}$ ($8.9\text{ mg/L}$), $\text{COD}$, and $\text{TSS}$.
* **Biomass & Bioenergy Kinetic Simulation**: Modeling $8,450\text{ kg/day}$ fresh extraction yielding $1,845\text{ m}^3\text{/day}$ raw biogas ($62.4\%\text{ CH}_4$) and $920\text{ kg/day}$ vehicular Bio-CNG.
* **Circular Economic Model**: Unit economics and 5-year break-even curve yielding $₹5.35\text{ Lakh/month}$ net benefit with a $2.8\text{-year}$ payback period.
* **Policy Report Generator**: Automated synthesis of high-resolution institutional PDF dossiers.

## 💻 9. Local Development & Build Guide

### Prerequisites
* **Node.js**: `v20.x` or higher
* **npm**: `v10.x` or higher
* **Git**: `v2.x`

### Step 1: Clone the Repository
```bash
git clone https://github.com/slockahuja/ganga-biocircularity-platform.git
cd ganga-biocircularity-platform
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Launch Local Development Server
```bash
npm run dev
```
Open your browser and navigate to: `http://localhost:5173/`

### Step 4: Run Production Build & Type Check
```bash
npm run build
```
The compiled, minified bundle will be output to the `./dist` folder.

## 🚀 10. Automated GitHub Pages Deployment

The repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`).

### To activate GitHub Pages on your repository:
1. Push the code to the `main` branch on GitHub:
   ```bash
   git add .
   git commit -m "feat: complete academic research & ganga biocircularity platform"
   git push origin main
   ```
2. In your GitHub repository:
   * Go to **Settings** → **Pages**.
   * Under **Build and deployment** → **Source**, select **GitHub Actions**.
3. The workflow will automatically build and publish the website to:
   **`https://slockahuja.github.io/ganga-biocircularity-platform/`**
